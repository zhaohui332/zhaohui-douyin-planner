# 兆辉防腐 · 抖音运营系统 云服务器部署指南

## 第一步：购买云服务器

推荐以下服务商（国内访问快）：

### 方案A：阿里云 轻量应用服务器（推荐）
- 链接：https://swas.aliyun.com
- 配置：**2核2G**（¥34/月，新用户 ¥24/月）
- 操作系统：选择 **Ubuntu 22.04**
- 地域：选离你最近的（华东/华南）

### 方案B：腾讯云 轻量服务器
- 链接：https://buy.cloud.tencent.com/lighthouse
- 配置：**2核2G**（¥34/月起）
- 操作系统：**Ubuntu 22.04**

> 如果你有阿里云/腾讯云账号，点链接直接买就行。
> 服务器买好之后会得到一个 **公网IP**，记下来。

---

## 第二步：登录服务器

### Windows 用户
下载 Putty：https://www.putty.org
- Host Name：你的服务器公网IP
- Port：22
- 用户名：root（或 ubuntu）
- 密码：买服务器时设的密码

### Mac 用户
打开「终端」，输入：
```bash
ssh root@你的服务器公网IP
```
然后输入密码。

---

## 第三步：一键部署

登录服务器后，复制粘贴下面这一行命令，按回车：

```bash
curl -sL https://raw.githubusercontent.com/zhaohui332/zhaohui-douyin-planner/main/outputs/deploy.sh | sudo bash
```

> 如果上面的下载链接不工作，也可以手动上传：
> 1. 电脑上打开 [deploy.sh](deploy.sh) 复制全部内容
> 2. 在服务器上执行 `nano deploy.sh` → 粘贴 → Ctrl+X → Y → 回车
> 3. 执行 `sudo bash deploy.sh`

脚本会自动完成：
- 安装 Node.js
- 从 GitHub 拉取代码
- 配置系统服务（开机自启）
- 开放防火墙端口

等待 1-2 分钟，看到 **「部署完成」** 字样即可。

---

## 第四步：访问系统

打开浏览器，访问：

```
http://你的服务器公网IP:3456
```

示例：如果你的服务器 IP 是 `123.123.123.123`，访问：
```
http://123.123.123.123:3456
```

---

## 第五步：配置 DeepSeek API（让AI功能能用）

1. 打开系统 → 点击左侧 **「系统设置」**
2. 在 DeepSeek API 配置处输入你的 API 密钥
3. 点击保存
4. **每个员工独立配置自己的密钥**，互不干扰

> 没有 API 密钥？去 https://platform.deepseek.com 注册获取

## 日常管理命令

SSH 登录服务器后使用：

```bash
# 查看服务状态
systemctl status zhaohui-douyin

# 重启服务（改完代码后）
systemctl restart zhaohui-douyin

# 查看实时日志（按 Ctrl+C 退出）
journalctl -u zhaohui-douyin -f

# 停止服务
systemctl stop zhaohui-douyin

# 更新代码（拉取 GitHub 最新版）
cd /opt/zhaohui-douyin && git pull && systemctl restart zhaohui-douyin
```

## 让所有员工都能用

### 方式1：直接给 IP 地址
把 `http://服务器IP:3456` 发给员工，打开浏览器就能用。
服务器需要开放 `3456` 端口（部署脚本已自动配置）。

### 方式2：绑定域名（推荐）
1. 买一个域名（阿里云/腾讯云都可以）
2. 添加 **A 记录** 指向服务器 IP
3. 员工访问 `http://你的域名:3456` 即可

### 安全建议
- 如果服务器暴露在公网，建议**定期修改 SSH 密码**
- 不需要让 AI 功能对所有人开放，DeepSeek API 每个员工用自己的密钥

## 常见问题

**Q: 页面打不开？**
A: 检查云服务器控制台的 **「防火墙/安全组」** 是否放行了 `3456` 端口

**Q: AI 功能报错？**
A: 检查是否在「系统设置」中配置了有效的 DeepSeek API 密钥

**Q: 如何让多个员工同时使用？**
A: 系统已支持多用户！每个员工在浏览器打开页面后，**输入自己的姓名**即可独立使用，互不干扰

**Q: 服务器重启后需要重新部署吗？**
A: 不需要。systemctl 服务已配置为开机自启。
