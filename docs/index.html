🚀 快速部署

买一台云服务器，一行命令搞定部署

1

购买云服务器

阿里云或腾讯云轻量应用服务器，Ubuntu 22.04，最低 ¥24/月

2

SSH 登录服务器

使用 ssh root@你的服务器IP 登录

3

一键部署

执行以下命令：

curl -sL https://raw.githubusercontent.com/zhaohui332/zhaohui-douyin-planner/main/outputs/deploy.sh | sudo bash

4

访问系统

浏览器打开 http://你的服务器IP:3456，输入姓名即可使用
